# Willkommen bei Project NOMAD

Ihr persönlicher Offline-Wissensserver ist einsatzbereit.

## Was ist NOMAD?

**NOMAD** ist ein Offline-First-Server für Wissen und Bildung. Es ist Ihr persönlicher Server für Wissen, Bildung und KI-Unterstützung – auch ohne Internetverbindung.

Stellen Sie es sich so vor: Wikipedia, Khan Academy, ein KI-Assistent und Offline-Karten an einem Ort, auf Hardware, die Sie selbst kontrollieren.

![Dashboard der Kommandozentrale](/docs/dashboard-de.webp)

## Was können Sie tun?

### Offline-Wissen durchsuchen
Greifen Sie auf Millionen von Wikipedia-Artikeln, medizinische Nachschlagewerke, Anleitungen und E-Books zu – alles lokal auf Ihrem Server gespeichert. Kein Internet erforderlich.

*Starten Sie die Wissensbibliothek über die Startseite oder das [Supply Depot](/supply-depot).*

### Etwas Neues lernen
Khan-Academy-Kurse zu Mathematik, Naturwissenschaften, Wirtschaft und mehr. Mit Videos und Übungen, alles offline verfügbar.

*Starten Sie die Bildungsplattform über die Startseite oder das [Supply Depot](/supply-depot).*

### Mit der KI chatten
Stellen Sie Fragen, lassen Sie sich Dinge erklären, sammeln Sie Ideen oder lassen Sie sich beim Schreiben helfen. Ihr lokaler KI-Assistent funktioniert völlig offline – und Sie können Dokumente in die Wissensdatenbank hochladen, damit die Antworten Ihre Unterlagen berücksichtigen.

**[KI-Chat öffnen →](/chat)**

### Dokumente in die Wissensdatenbank hochladen
Laden Sie PDFs, Textdateien und andere Dokumente hoch, auf die die KI zugreifen kann. Die Wissensdatenbank nutzt die semantische Suche, um bei Ihren Fragen passende Informationen aus Ihren hochgeladenen Dokumenten zu finden.

**[Wissensdatenbank öffnen →](/knowledge-base)**

### Offline-Karten ansehen
Navigieren und erkunden Sie Karten ohne Internetverbindung. Laden Sie die benötigten Regionen herunter, bevor Sie offline gehen.

**[Karten öffnen →](/maps)**

### Ihre Hardware testen
Führen Sie einen System-Benchmark aus, um zu sehen, wie leistungsfähig Ihre Hardware ist, und vergleichen Sie Ihren NOMAD Score mit der Community-Bestenliste.

**[Benchmark öffnen →](/settings/benchmark)**

## Ihren Server aktuell halten

NOMAD funktioniert am besten, wenn Sie es aktuell halten, solange Sie Internetzugang haben. So haben Sie jeweils die neuesten:
- Software-Funktionen und Fehlerbehebungen
- Wikipedia- und Nachschlageinhalte
- Lernmaterialien
- Verbesserungen der KI-Modelle

Wenn Sie offline gehen, haben Sie alles, was Sie brauchen – den zuletzt synchronisierten Stand aller Ihrer Inhalte.

Sie können auf Wunsch aktualisieren oder **automatische Updates** einschalten, damit NOMAD Software, Apps und Inhalte selbstständig aktuell hält, solange Sie Internet haben. Wie das funktioniert, lesen Sie in der **[Anleitung „Updates“](/docs/updates)**.

**[Nach Updates suchen →](/settings/update)**
