# Über Project NOMAD

Project NOMAD („NOMAD“ kurz) ist ein 2025 von Chris Sherwood von [Crosstalk Solutions, LLC](https://crosstalksolutions.com) gestartetes Projekt. Ziel ist nicht, einfach ein weiteres Werkzeug zum Speichern von Offline-Ressourcen zu schaffen, sondern Nutzern zu ermöglichen, ihren eigenen ultimativen „Überlebenscomputer“ zu betreiben. Der Name entstand zunächst als Backronym – Node for Offline Maps, Archives, and Data –, heute sagen wir aber einfach NOMAD.

Während viele ähnliche Offline-Überlebenscomputer für minimale, leichtgewichtige Hardware ausgelegt sind, ist Project NOMAD das genaue Gegenteil. Um die verfügbaren KI-Werkzeuge zu installieren und auszuführen, empfehlen wir dringend ein leistungsstarkes Gerät mit GPU, damit Sie Ihre Installation voll ausschöpfen können. Detaillierte Empfehlungen für drei Preisklassen finden Sie im [Hardware-Leitfaden](https://www.projectnomad.us/hardware).

Seit der ersten Veröffentlichung ist NOMAD um einen integrierten KI-Chat mit Wissensdatenbank für dokumentbasierte Antworten, einen System-Benchmark mit Community-Bestenliste, kuratierte Inhaltssammlungen mit gestuften Optionen und einen Schnellstart-Assistenten gewachsen, der neuen Nutzern den schnellen Einstieg erleichtert.

Project NOMAD ist Open Source und steht unter der [Apache License 2.0](https://github.com/Crosstalk-Solutions/project-nomad/blob/main/LICENSE).
